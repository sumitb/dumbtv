# Amazon packages to disable on Fire OS 6 (Android 7.1, sdk 25). Fire OS 6 has no
# `cmd package install-existing`, so debloat.sh never uninstalls these: it only
# disables them, which restore.sh undoes with `pm enable`.
#
# Built from data/fireos/packages.txt, checked package by package on a Fire TV
# Stick 4K (mantis, AFTMM) running Fire OS 6.7.1.1. Entries marked "fire os 6"
# are not in the Fire OS 7 list; they were disabled on that stick and it kept
# booting, the remote kept working and the streaming apps kept launching.
#
# Deliberately NOT here on Fire OS 6:
#   com.amazon.firebat        on Fire OS 6 this is Prime Video itself
#                             (com.amazon.pyrocore.IgnitionActivity), not an OTA helper
#   com.amazon.ftv.screensaver  only runs while the TV is idle; without it and with
#                             com.android.dreams.basic off, nothing covers a static screen
